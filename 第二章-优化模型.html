01 线性规划

Linear Programming

最基础也最强大的优化方法 — 目标函数与约束条件均为线性

LP
标准形式
Standard Form
所有线性规划问题都可以转化为标准形式：在线性等式约束下，最小化线性目标函数。
min cTx
s.t. Ax = b
     x ≥ 0
S
单纯形法
Simplex Method
沿可行域顶点迭代搜索。虽然最坏情况是指数级，但在实践中通常非常高效。由 Dantzig 于 1947 年提出。
1. 找初始基可行解
2. 检验数判断最优
3. 换基迭代直到最优
D
对偶理论
Duality Theory
每个线性规划问题都有一个对偶问题。强对偶定理：原问题与对偶问题的最优值相等。对偶变量即为影子价格。
原问题 min cTx
对偶 max bTy
s.t. ATy ≤ c
~
灵敏度分析
Sensitivity Analysis
分析参数变化对最优解的影响。哪些资源最紧缺？目标函数系数变化多少不影响方案？
影子价格 = ∂z*/∂bᵢ
允许变化范围
保持当前基最优

03 动态规划

Dynamic Programming

将复杂问题分解为重叠子问题，通过最优子结构递推求解

1
定义状态
确定描述问题进展的状态变量 s，通常需要能唯一标识每个子问题
2
状态转移方程
找到从已知状态推导未知状态的递推关系 — 这是 DP 的核心
3
确定边界
给出初始条件（base case），通常是问题规模最小时的直接解
4
计算顺序
自底向上（递推）或自顶向下（记忆化搜索），确保计算某状态时其依赖状态已求出
5
回溯最优方案
根据记录的决策路径，从最终状态反向追踪得到最优解对应的具体方案
K
背包问题
Knapsack Problem
DP 经典。给定背包容量和物品重量/价值，选择物品使总价值最大。状态转移：dp[i][w] = max(dp[i-1][w], dp[i-1][w-wᵢ]+vᵢ)
dp[i][w] = max(
  dp[i-1][w],
  dp[i-1][w-wᵢ] + vᵢ
)
R
资源分配
Resource Allocation
将有限资源分配给多个阶段/项目使总收益最大。典型 DP 应用：阶段 × 资源量构成二维状态空间。
f(k, r) = max0≤x≤r{
  g(k, x) + f(k+1, r-x)
}

04 竞赛应用

实战指南

优化模型在数学建模竞赛中的高频应用场景

🚚
运输调度
Transportation Problem
经典的产销平衡问题。多个供应点到多个需求点的最优运输方案，目标是总运费最小。可扩展为转运问题。
LP表上作业法伏格尔法
📦
选址问题
Facility Location
在候选位置中选择设施点，使建设成本与运输成本之和最小。典型 0-1 整数规划问题。
MIP0-1规划覆盖模型
🔄
排班调度
Scheduling
员工排班、任务调度、机器作业排序。目标通常是最大化效率或最小化等待时间。NP-hard，启发式求解。
IP贪心遗传算法
💡
投资组合
Portfolio Optimization
Markowitz 均值-方差模型。在给定期望收益下最小化风险（方差），或在给定风险下最大化收益。二次规划。
min ½ xTΣx
s.t. μTx ≥ r₀
     1Tx = 1
