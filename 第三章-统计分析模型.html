01 回归分析

Regression Analysis

研究因变量与自变量之间的依赖关系 — 统计建模最基础的工具

LR
线性回归
Linear Regression
假设因变量 y 与自变量 x 之间存在线性关系。用最小二乘法估计参数，使残差平方和最小。
y = β₀ + β₁x₁ + ... + βₚxₚ + ε

β̂ = (XTX)-1XTy
OLS最小二乘R²
MLR
多元回归
Multiple Regression
多个自变量的线性回归。需要关注多重共线性（VIF）、变量选择（逐步回归、AIC/BIC）和残差诊断。
F 检验: 整体显著性
t 检验: 单个系数
VIF: 多重共线性诊断
VIF逐步回归AIC
Log
逻辑回归
Logistic Regression
因变量为分类变量（0/1）。用 Sigmoid 函数将线性组合映射到 [0,1] 概率空间。最大似然估计求解。
P(y=1|x) = 1 / (1 + e-z)
z = β₀ + β₁x₁ + ... + βₚxₚ
SigmoidMLEROC曲线
NLR
非线性回归
Nonlinear Regression
变量间存在非线性关系：指数、对数、幂函数、S 型曲线等。通过变量变换或迭代优化求解。
常见模型:
y = aebx (指数)
y = a·ln(x) + b (对数)
y = axb (幂函数)
变量变换Gauss-NewtonLevenberg
0回归类型
0核心检验
0拟合优度指标
02 方差分析

ANOVA

检验多个总体均值是否存在显著差异 — 分解总变异为组间与组内

1F
单因素方差分析
One-Way ANOVA
研究一个因素的不同水平对因变量的影响。F = 组间方差 / 组内方差，F 值越大说明因素影响越显著。
SS总 = SS组间 + SS组内
F = MS组间 / MS组内
p < α 则拒绝 H₀
2F
双因素方差分析
Two-Way ANOVA
同时研究两个因素对因变量的影响，还能检测两因素之间的交互效应。分解为：行因素 + 列因素 + 交互 + 误差。
SS总 = SSA + SSB + SSAB + SSE
检验: FA, FB, FAB
1
提出假设
H₀: μ₁ = μ₂ = ... = μₖ（各组均值相等）；H₁: 至少一对不等
2
计算平方和
总变异 = 组间变异 + 组内变异。SST = ΣΣ(xᵢⱼ - x̄)²
3
构造 F 统计量
F = MSbetween / MSwithin，服从 F(k-1, N-k) 分布
4
事后多重比较
若 F 显著，用 Tukey HSD、Bonferroni 等方法确定哪些组之间存在差异
03 主成分分析

PCA

降维的利器 — 用少数几个综合变量尽可能多地保留原始信息

PCA
核心思想
Principal Component Analysis
在高维数据中找到方差最大的方向作为第一主成分，次大方差正交方向为第二主成分，以此类推。实现降维的同时最大化信息保留。
Z = XW
W = eigenvectors of XTX
λ₁ ≥ λ₂ ≥ ... ≥ λₚ
K
选择主成分个数
Component Selection
通常选择累计贡献率达到 80%~90% 的前 k 个主成分。碎石图（Scree Plot）拐点处也是常用的截断依据。
贡献率 = λᵢ / Σλᵢ
累计贡献率 = Σj=1k λⱼ / Σλᵢ
通常取 ≥ 85%
1
数据标准化
消除量纲影响：z = (x - μ) / σ，使各变量具有可比性
2
计算协方差矩阵
C = XTX / (n-1)，反映变量间的线性相关程度
3
特征值分解
对协方差矩阵做特征值分解，得到特征值（方差贡献）和特征向量（主成分方向）
4
选择并投影
选择前 k 个主成分，将原始数据投影到新的低维空间
04 聚类分析

Cluster Analysis

无监督学习的经典方法 — 让数据自己"说出"内在的分组结构

KM
K-Means 聚类
K-Means Clustering
最经典的划分方法。指定 K 个簇，迭代执行：分配每个点到最近质心 → 更新质心 → 重复直到收敛。
1. 随机初始化 K 个质心
2. 分配: C(i) = argmin‖xᵢ-μₖ‖²
3. 更新: μₖ = mean(x ∈ Cₖ)
4. 重复直到收敛
肘部法则轮廓系数K-Means++
HC
层次聚类
Hierarchical Clustering
不需要预设 K 值。自底向上（凝聚）或自顶向下（分裂），生成树状图（Dendrogram）直观展示聚类过程。
凝聚法:
1. 每个点为一个簇
2. 合并最近的两个簇
3. 重复直到达到目标
链接: single / complete / average
树状图距离矩阵Ward法
DB
DBSCAN
Density-Based Clustering
基于密度的聚类。能发现任意形状的簇，自动识别噪声点。不需要预设 K 值，但需要设定邻域半径 ε 和最小点数 MinPts。
核心点: 邻域内 ≥ MinPts 个点
边界点: 在核心点邻域内
噪声点: 既非核心也非边界
ε邻域噪声检测任意形状
EV
聚类评估
Cluster Evaluation
如何评价聚类效果？内部指标（轮廓系数、Calinski-Harabasz）不需要标签；外部指标（ARI、NMI）需要真实标签。
轮廓系数:
s(i) = (b(i)-a(i)) / max(a(i),b(i))
a(i): 簇内平均距离
b(i): 最近簇平均距离
轮廓系数CH指数DB指数
特性K-Means层次聚类DBSCAN
需要预设K是否否
簇形状球形任意任意
噪声处理差一般优秀
